--------------------------------------------------------------------------------
USAGE NOTES
--------------------------------------------------------------------------------

For deployment where the model might encounter out-of-distribution genera:

1. Use a HIGHER threshold (0.7-0.9) if:
   - Misidentification has serious consequences
   - You prefer 'I don't know' over wrong answers
   - User can provide more images for unsure cases

2. Use a MODERATE threshold (0.5-0.7) if:
   - You want balanced precision and coverage
   - Most inputs are from the 500 known genera
   - Some uncertainty is acceptable

3. Use a LOWER threshold (0.3-0.5) if:
   - Coverage is critical (must provide some answer)
   - Errors can be corrected by user
   - This is for suggestions, not final decisions

4. Use NO threshold (0.0) if:
   - All inputs guaranteed to be from the 500 known genera
   - User understands model limitations
   - Display top-k predictions instead of just top-1
