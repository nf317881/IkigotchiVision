QUALITY FILTERING CRITERIA
================================================================================

Minimal Quality Filter (Applied to all data):

2. Exclude records with TAXON_MATCH_HIGHERRANK issue flag (~0.02% of data)
3. Require mediaType = 'StillImage'

NOTE: Location-related filtering removed (hasCoordinate, hasGeospatialIssues,
      coordinateUncertainty) - not needed for image classification task

Expected Data Loss: ~0.2% (minimal impact on image counts)
- Rank 500 (Ziziphus): 892 → ~890 images (still above 800 target)

================================================================================
STRATIFIED SAMPLING STRATEGY
================================================================================

Three-level stratification for maximum diversity:

Level 1: Genus (top 500 by image count)
  └─ Level 2: Species within genus
       └─ Level 3: Plant organ type (flower, leaf, fruit, bark, habit, other)

Sampling Process per Genus:
1. Group all images by species
2. Within each species, group by organ type
3. Calculate proportional sampling from each species-organ combination
4. Sample 800 images total (or all available if <800)

Rationale:
- Species stratification: Ensures genetic diversity within genus
- Organ stratification: Ensures model learns from multiple plant parts
- Proportional sampling: Maintains natural distribution patterns

Plant Organ Distribution (overall dataset):
- Flower: 50.9% (1,611,343 images)

- Fruit: 6.3% (199,849 images)
- Habit: 3.3% (105,311 images)
- Bark: 1.7% (53,459 images)
- Other: 0.4% (13,195 images)

================================================================================
IMPLEMENTATION STEPS
================================================================================

Step 1: Parse and Filter Occurrence Data
- Load occurrence.txt (2.6M records)
- Filter by quality criteria (exclude taxonomic issues)
- Extract: gbifID, genus, species, scientificName, issue flags
- Output: filtered_occurrences.csv

Step 2: Parse Multimedia Data
- Load multimedia.txt (3.2M records)
- Extract: gbifID, image URL, plant organ (from description), license
- Output: image_metadata.csv

Step 3: Join Occurrence and Multimedia Data
- Match on gbifID
- Create combined dataset with: genus, species, organ, image_url
- Output: combined_data.csv

Step 4: Identify Top 500 Genera
- Count images per genus (after filtering)
- Rank genera by image count
- Select top 500 genera
- Verify all have sufficient images (or note which have <800)
- Output: top_500_genera.txt with counts

Step 5: Stratified Sampling
- For each of 500 genera:
  * Group images by (species, organ)
  * Calculate sampling proportions
  * Sample 800 images (or all if <800)
  * Assign to train/val/test (80/10/10 split)
- Output: selected_images.csv

Step 6: Download and Process Images
- Download images from Pl@ntNet URLs
- Process each image:
  * If not square: Center crop to square (min dimension)
  * Resize to 224x224 pixels
  * Save as JPEG (quality=95)
- Organize into train/val/test/genus folders
- Handle download errors (retry, log failures)
- Verify image integrity (format, readability)
- Save with standardized naming: {genus_id}_{image_id}.jpg

Image Processing Pipeline:
1. Download original image from URL
2. Open with PIL/Pillow
3. Center crop:
   - Calculate crop size = min(width, height)
   - Crop from center: ((width-crop_size)//2, (height-crop_size)//2)
4. Resize square to 224x224 using high-quality resampling (LANCZOS)
5. Save as JPEG with quality=95

Step 7: Generate Metadata Files
- Create label_mapping.json (genus_id → genus_name)
- Create manifest CSVs with columns:
  * file_path
  * genus_id
  * genus_name
  * species_name
  * organ_type
  * original_url
  * license
- Generate statistics report:
  * Images per genus (min/max/mean/median)
  * Species per genus
  * Organ distribution per genus
  * Train/val/test counts
  * Download success rate

Step 8: Quality Validation
- Verify all images are readable
- Check class balance
- Verify train/val/test splits
- Generate summary visualizations (optional):
  * Class distribution histogram
  * Organ type distribution
  * Species diversity per genus
