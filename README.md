## Overview

IkigotchiVision is a collection of Vision Transformer (ViT) models designed for plant classification tasks. The project includes three implementations ranging from house plant identification to large-scale plant genus classification across 500 genera.

**What makes this special:**
- **92% accuracy** on 500-class plant genus classification
- **Optimized for 8GB VRAM** consumer GPUs
- **Mobile-ready** with ONNX export and FP16 quantization
- **Confidence thresholding** for handling out-of-distribution samples
- **Stronger regularization** techniques (Mixup, CutMix, RandAugment)
- **Comprehensive evaluation tools** including confusion matrices, attention maps, and threshold analysis

## Key Features

### Core Capabilities
- **Multiple Model Scales**: Tiny, Small, and Base variants to fit different hardware constraints
- **Transfer Learning**: Pretrained on ImageNet-21k for faster convergence and better accuracy
- **Advanced Augmentation**: Mixup, CutMix, RandAugment, and test-time augmentation (TTA)
- **Production Ready**: ONNX export with FP16 quantization (50% model size reduction)
- **Confidence Calibration**: Built-in threshold analysis for production deployment

### Training Features
- **Mixed Precision Training (AMP)**: 2x faster training
- **Automatic Resume**: Never lose training progress
- **Cosine Annealing**: Optimal learning rate scheduling
- **Early Stopping**: Prevent overfitting with patience-based stopping
- **Comprehensive Checkpointing**: Save best and latest models automatically

### Evaluation Tools
- Confusion matrices and per-class accuracy
- Attention map visualization
- Top-K accuracy curves
- Confidence threshold analysis
- Detailed classification reports

## Usage

### Broader Transformer (500 Genera)

#### 1. Data Preparation

Download GBIF occurrence data:
- Visit: [GBIF Plant Dataset](https://www.gbif.org/dataset/7a3679ef-5582-4aaa-81f0-8c2545cafc81/project)
- Download `occurrence.txt` and `multimedia.txt`
- Place in `broader_transformer/data/`

Process the data:
```bash
cd broader_transformer

```

This creates:
- `processed_data/images/train/` - Training images (320K)
- `processed_data/images/val/` - Validation images (40K)
- `processed_data/images/test/` - Test images (40K)
- `processed_data/metadata/label_mapping.json` - Genus mappings

#### 2. Training

**Standard training (v1):**
```bash
python train.py
```

**With stronger regularization (v2):**
Edit `train.py` config:
```python
config = {
    'label_smoothing': 0.2,      # Increased from 0.1
    'learning_rate': 1e-4,       # Lower LR
    'stronger_aug': True,        # RandAugment, RandomErasing
    'use_mixup': True,           # Mixup augmentation
    'use_cutmix': True,          # CutMix augmentation
    'save_dir': 'checkpoints_v2' # Separate directory
}
```

**Training time**: ~30 hours for 100 epochs (8GB GPU)

#### 3. Evaluation

```bash
# Standard evaluation
python evaluate.py

# Confidence threshold analysis
python evaluate_confidence_thresholds.py --checkpoint_dir checkpoints_v2 --dataset test
```

#### 4. Inference Example

```python
import torch
from PIL import Image
from model import create_genus_vit_pretrained
from dataset import get_val_transforms
import json

# Load model
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = create_genus_vit_pretrained(
    model_name='vit_small_patch16_224.augreg_in21k_ft_in1k',
    num_classes=500,
    pretrained=False
)
checkpoint = torch.load('checkpoints_v2/best_checkpoint.pth')
model.load_state_dict(checkpoint['model_state_dict'])
model = model.to(device)
model.eval()

# Load label mapping
with open('processed_data/metadata/label_mapping.json') as f:
    genus_to_id = json.load(f)['genus_to_id']
id_to_genus = {v: k for k, v in genus_to_id.items()}

# Prepare image
transform = get_val_transforms(img_size=224)
image = Image.open('plant.jpg').convert('RGB')
image_tensor = transform(image).unsqueeze(0).to(device)

# Predict with confidence threshold
with torch.no_grad():
    output = model(image_tensor)
    probs = torch.softmax(output, dim=1)
    confidence, prediction = probs.max(dim=1)

    # Apply 0.5 confidence threshold
    if confidence.item() >= 0.5:
        genus = id_to_genus[prediction.item()]
        print(f"Prediction: {genus} ({confidence.item()*100:.1f}% confidence)")
    else:
        print(f"Unsure - confidence below threshold ({confidence.item()*100:.1f}%)")
```

#### Use ONNX Model

```python
import onnxruntime as ort
import numpy as np
from PIL import Image

# Load ONNX model
session = ort.InferenceSession("checkpoints_v2/model_fp16.onnx")

# Prepare image (224x224, normalized)
img = Image.open("plant.jpg").convert("RGB").resize((224, 224))
img_array = np.array(img).transpose(2, 0, 1).astype(np.float32) / 255.0
img_array = (img_array - np.array([0.485, 0.456, 0.406]).reshape(3, 1, 1)) / \
            np.array([0.229, 0.224, 0.225]).reshape(3, 1, 1)
img_array = np.expand_dims(img_array, axis=0)

# Run inference
outputs = session.run(None, {'input': img_array})
probabilities = outputs[0]

# Get prediction
predicted_class = np.argmax(probabilities)
confidence = probabilities[0][predicted_class]
print(f"Class: {predicted_class}, Confidence: {confidence:.2%}")
```

## Architecture

### Vision Transformer (ViT-Small)

Based on "An Image is Worth 16x16 Words" (Dosovitskiy et al., 2021)

**Model Specifications:**
- **Input Size**: 224x224 RGB
- **Patch Size**: 16x16 (produces 14x14 = 196 patches)
- **Embedding Dimension**: 384
- **Transformer Layers**: 12
- **Attention Heads**: 6
- **MLP Ratio**: 4.0
- **Parameters**: ~22M
- **FLOPs**: ~4.6 GFLOPs per image

**Key Components:**
1. **Patch Embedding**: Splits image into 16x16 patches with linear projection
2. **Positional Encoding**: Learnable 2D positional embeddings
3. **Class Token**: Learnable [CLS] token for classification
4. **Transformer Encoder**: Multi-head self-attention + Feed-forward network
5. **Classification Head**: Linear layer mapping [CLS] token to class logits

**Pretrained Weights**: `vit_small_patch16_224.augreg_in21k_ft_in1k`
- Pretrained on ImageNet-21k (14M images, 21k classes)
- Fine-tuned on ImageNet-1k (1.3M images, 1k classes)
- Provides ~3-5% accuracy boost vs training from scratch

## Training Details

### Data Augmentation

#### Baseline (v1)
- Random horizontal flip (50%)
- Random rotation (±10°)
- Color jitter (brightness, contrast, saturation)
- Random affine transformations
- Normalization (ImageNet stats)

#### Stronger Augmentation (v2)
- Random resized crop (70-100% scale)
- Random rotation (20%, increased)
- **RandAugment** (magnitude 9, 2 ops)
- **Mixup** (0.2, 50% probability)
- **CutMix** (1.0, 50% probability)
- **RandomErasing** (25% probability)
- Color jitter (stronger)

### Hyperparameters

| Parameter | v1 (Baseline) | v2 (Stronger Reg) |
|-----------|---------------|-------------------|
| **Optimizer** | AdamW | AdamW |
| **Learning Rate** | 3e-4 | 1e-4 |
| **Weight Decay** | 1e-4 | 1e-4 |
| **Label Smoothing** | 0.1 | 0.2 |
| **Batch Size** | 64 | 64 |
| **Epochs** | 100 | 100 |
| **Scheduler** | Cosine Annealing | Cosine Annealing |
| **Early Stopping** | 15 epochs patience | 15 epochs patience |

### Training Features

- **Mixed Precision (AMP)**: Automatic mixed precision for 2x speedup
- **Automatic Resume**: Resumes from latest checkpoint if interrupted
- **Real-time Monitoring**: tqdm progress bars with loss/accuracy
- **Dual Checkpointing**: Saves both best (by val acc) and latest models
- **Visualization**: Automatic training curve plots
